# geometry

Computational geometry basics, standard library only.

- `convex_hull.py` — Andrew's monotone chain hull with a self-check.
- `polygon_area.py` — shoelace area, centroid and point-in-polygon.
- `segment_intersect.py` — segment intersection test and intersection point.
- `closest_pair.py` — divide-and-conquer closest pair of points, checked against brute force.
- `point_in_triangle.py` — triangle area, barycentric containment and circumcircle.
- `minimum_enclosing_circle.py` — smallest circle enclosing a point set.
