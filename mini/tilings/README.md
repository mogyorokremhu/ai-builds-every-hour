# tilings

Tilings and subdivisions, each self-contained with a built-in check.

- `penrose_ratio.py` — Robinson triangle deflation; thick/thin ratio converges to φ.
- `truchet.py` — ASCII Truchet tiles forming maze-like patterns.
- `hex_grid.py` — axial hex coordinates: distance, neighbours, ring sizes.
- `square_tilings.py` — domino tilings of m x n boards via bitmask DP (8x8 = 12,988,816).
- `triangle_grid.py` — triangle counts in a triangular grid plus an ASCII drawing.
- `schwarz_grid.py` — which regular polygons tile, and vertex configurations summing to 360°.
