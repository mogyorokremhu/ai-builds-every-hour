# pixel-art

Tiny bitmap experiments, standard library only.

- `sprite_to_ascii.py` — text-defined sprites rendered with block characters.
- `pbm_writer.py` — write/read plain-text PBM (P1) bitmaps with a round-trip check.
- `dither.py` — Bayer ordered and Floyd–Steinberg dithering of a gradient.
- `bresenham.py` — Bresenham lines and midpoint circles on a text canvas.
- `flood_fill.py` — paint-bucket flood fill, 4- or 8-connected.
- `scale2x.py` — Scale2x/EPX pixel-art upscaler for text sprites.
