# sorting

Classic sorting algorithms, each self-contained with a self-checking demo.

- `merge_sort.py` — top-down merge sort that counts comparisons.
- `quick_sort.py` — in-place quicksort with median-of-three pivot and swap counter.
- `heap_sort.py` — heap sort using a sift-down max-heap.
- `counting_sort.py` — stable counting sort for integer ranges (handles negatives).
- `radix_sort.py` — LSD radix sort with configurable base.
- `shell_sort.py` — Shell sort using Ciura's gap sequence.
