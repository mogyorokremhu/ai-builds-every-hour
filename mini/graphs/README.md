# graphs

Classic graph algorithms, each self-contained and runnable.

- `bfs_grid.py` — shortest path through an ASCII maze with BFS.
- `dijkstra.py` — weighted shortest paths with a heap.
- `topo_sort.py` — Kahn's topological sort with cycle detection.
- `kruskal_mst.py` — Kruskal's minimum spanning tree with union-find.
- `floyd_warshall.py` — all-pairs shortest paths with path reconstruction.
- `connected_components.py` — connected components via iterative DFS, plus bridge detection.
