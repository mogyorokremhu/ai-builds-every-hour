# quizzes

Tiny terminal quizzes, standard library only. Each supports `--auto` (and `--seed`) to run unattended.

- `math_quiz.py` — random arithmetic questions with a final score.
- `capitals_quiz.py` — multiple-choice world capitals.
- `trivia_streak.py` — true/false trivia where consecutive right answers score more.
- `binary_quiz.py` — convert binary and hex numbers to decimal.
- `roman_quiz.py` — write numbers as Roman numerals.
- `unit_quiz.py` — metric/imperial unit conversions, 1% tolerance.
