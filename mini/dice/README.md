# dice

Tiny dice utilities (standard library only).

- `dice_notation.py` — parse/roll `3d6+2`, `4d6kh3` style notation.
- `yahtzee_score.py` — score a five-dice roll in all Yahtzee categories.
- `dice_odds.py` — exact sum distribution for NdS with a text histogram.
- `coin_flip_runs.py` — simulate coin flips and histogram the run lengths.
- `craps_sim.py` — pass-line craps simulation vs. the exact 244/495 win rate.
- `bag_draw.py` — shuffled-bag die roller that avoids long streaks.
