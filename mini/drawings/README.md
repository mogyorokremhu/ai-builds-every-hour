# 🎨 Drawings

Small, self-contained Python art scripts. Most use the built-in `turtle` module
(`python file.py` opens a window); `ascii_*` ones print to the terminal.

| File | What it draws |
|---|---|
| `spiral_galaxy.py` | Golden-angle spiral of rainbow dots |
| `fractal_tree.py` | Recursive tree, brown trunk to green tips |
| `ascii_mandelbrot.py` | Mandelbrot set in ASCII characters |
| `star_flower.py` | 72 rotated five-pointed stars |
| `night_city.py` | Random skyline with lit windows and a moon |
| `sierpinski.py` | Sierpinski triangle via the chaos game |
| `koch_snowflake.py` | Koch snowflake (depth 4) in icy blues |
| `dragon_curve.py` | Heighway dragon from an L-system, rainbow along its length |
| `hilbert_curve.py` | Order-6 Hilbert space-filling curve, violet → gold |
| `ascii_mountains.py` | Three midpoint-displacement ridgelines, moon and stars (`python ascii_mountains.py 42`) |
| `ascii_lissajous.py` | Four Lissajous figures side by side, denser where the curve crosses |
| `ascii_julia.py` | Julia sets: a tour of classic constants or your own `re im` |
| `ascii_voronoi.py` | Voronoi cells with borders and sites (`python ascii_voronoi.py 25 7 --manhattan`) |
| `ascii_fern.py` | Barnsley fern grown by the chaos game, density-shaded (`--mutant` for a Cyclosorus fern) |
| `ascii_truchet.py` | Random Truchet tiles whose quarter-circle arcs join into winding paths (`--diagonal`, `--seed`) |
| `ascii_moon.py` | Today's (or any date's) Moon phase with limb shading; `--month` shows the next 30 days |
| `ascii_spirograph.py` | Hypotrochoid/epitrochoid gallery, or your own `R r d [--epi]` |
| `ascii_penrose.py` | Penrose P3 rhombus tiling from subdivided Robinson triangles (`python ascii_penrose.py 6`) |
| `ascii_sine_waves.py` | Three sine waves and their interference sum |
| `ascii_checker_zoom.py` | Rotating, zooming checkerboard frames side by side |
| `ascii_plasma.py` | Demo-scene plasma as shaded ASCII (`python ascii_plasma.py 2.5`) |
| `ascii_lorenz.py` | Lorenz attractor density plot |
| `ascii_hex_grid.py` | Hexagonal board with axial coordinates (`python ascii_hex_grid.py 3`) |
| `ascii_rose.py` | Rhodonea rose curves for any `k`, including fractions (`python ascii_rose.py 5/3`) |
| `ascii_sierpinski_carpet.py` | Sierpinski carpet of any depth (`python ascii_sierpinski_carpet.py 3`) |
| `ascii_pascal_triangle.py` | Pascal's triangle, odd entries marked — a Sierpinski triangle appears |
| `ascii_concentric.py` | Two-centre ring interference (moire) pattern |
| `ascii_cardioid.py` | Cardioid string art: chords from point k to 2k on a circle |
| `ascii_diamond_square.py` | Diamond-square terrain heightmap, shaded (`python ascii_diamond_square.py 7`) |
| `ascii_waves_interference.py` | Ripples from three point sources interfering |
| `ascii_dragon_curve.py` | Heighway dragon on a character grid, any order (`python ascii_dragon_curve.py 10`) |
| `ascii_burning_ship.py` | Burning Ship fractal in shaded ASCII |
| `ascii_maze_walk.py` | Recursive-backtracker maze (`python ascii_maze_walk.py 20 8 3`) |
