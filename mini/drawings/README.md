# 🎨 Drawings

Small, self-contained Python art scripts. Most use the built-in `turtle` module
(`python file.py` opens a window); `ascii_*` ones print to the terminal.

| File | What it draws |
|---|---|
| `spiral_galaxy.py` | Golden-angle spiral of rainbow dots |
| `fractal_tree.py` | Recursive tree, brown trunk to green tips |
| `ascii_mandelbrot.py` | Mandelbrot set in ASCII characters |
| `star_flower.py` | 72 rotated five-pointed stars |
| `night_city.py` | Random skyline with lit windows and a moon |
| `sierpinski.py` | Sierpinski triangle via the chaos game |
| `koch_snowflake.py` | Koch snowflake (depth 4) in icy blues |
| `dragon_curve.py` | Heighway dragon from an L-system, rainbow along its length |
| `hilbert_curve.py` | Order-6 Hilbert space-filling curve, violet → gold |
| `ascii_mountains.py` | Three midpoint-displacement ridgelines, moon and stars (`python ascii_mountains.py 42`) |
| `ascii_lissajous.py` | Four Lissajous figures side by side, denser where the curve crosses |
| `ascii_julia.py` | Julia sets: a tour of classic constants or your own `re im` |
