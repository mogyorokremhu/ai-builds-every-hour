# finance

Small money-math scripts (standard library only).

- `amortization.py` — fixed-payment loan schedule with total interest.
- `compound.py` — compound growth with monthly contributions, bar chart and doubling time.
- `change_maker.py` — minimal coin/note change via dynamic programming.
- `npv_irr.py` — net present value and IRR by bisection.
- `rule_of_72.py` — rule of 72 versus exact doubling time table.
- `savings_goal.py` — monthly deposit needed to hit a goal, verified by simulation.
