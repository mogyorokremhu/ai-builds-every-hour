# calendar

Date math from scratch, each file self-checks against `datetime`/`calendar`.

- `day_of_week.py` — Zeller's congruence for the weekday of any Gregorian date.
- `easter.py` — Easter Sunday via the anonymous Gregorian algorithm.
- `calendar_print.py` — renders a Monday-first month calendar with leap-year logic.
- `week_number.py` — ISO 8601 week number/year via the Thursday rule.
- `julian_day.py` — Julian Day Number to/from Gregorian dates.
- `days_between.py` — day counts and business days from a days-from-civil algorithm.
- `moon_phase.py` — moon age and phase name from the mean synodic month.
- `leap_years.py` — O(1) leap-year counting over a range and next-leap lookup.
- `countdown.py` — years/months/days between two dates with month borrowing.
- `nth_weekday.py` — nth/last weekday of a month; US and EU DST switch dates, Thanksgiving.
- `friday13.py` — Friday-the-13th finder and 400-year cycle statistics.
- `doomsday.py` — Conway's Doomsday rule for the weekday of any date.
