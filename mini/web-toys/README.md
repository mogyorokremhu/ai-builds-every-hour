# web-toys

Single-file HTML toys: open in a browser, no build step.

- `bouncing_balls.html` — click to spawn gravity-bound bouncing balls with trails.
- `color_mixer.html` — RGB sliders with live hex and HSL readout.
- `typing_speed.html` — type the sentence, get WPM and error count.
- `pendulum.html` — chaotic double pendulum with a trail; click to re-randomize.
- `life.html` — Conway's Life on a wrapping grid; draw cells, pause, randomize.
- `reaction_time.html` — click when the screen turns green; tracks your best time.
