# web-toys

Single-file HTML toys: open in a browser, no build step.

- `bouncing_balls.html` — click to spawn gravity-bound bouncing balls with trails.
- `color_mixer.html` — RGB sliders with live hex and HSL readout.
- `typing_speed.html` — type the sentence, get WPM and error count.
- `pendulum.html` — chaotic double pendulum with a trail; click to re-randomize.
- `life.html` — Conway's Life on a wrapping grid; draw cells, pause, randomize.
- `reaction_time.html` — click when the screen turns green; tracks your best time.
- `starfield.html` — fly through a 3D starfield; mouse steers, click/key warps.
- `drum_pad.html` — synthesised drum pad (Web Audio), click or use Q W E R / A S D F.
- `maze_runner.html` — walk a freshly generated perfect maze to the red square.
- `tic_tac_toe.html` — play X against an unbeatable minimax AI.
- `sand_fall.html` — falling-sand automaton; drag to pour three colours of sand.
- `snake.html` — classic wrapping snake that speeds up with every apple.
- `lissajous.html` — Lissajous curve with sliders for the two frequencies and phase; colour drifts.
- `gravity_wells.html` — 400 particles orbit gravity wells you click to add (shift+click removes).
- `whack_a_mole.html` — 30-second whack-a-mole that speeds up as your score climbs.
- `etch_sketch.html` — Etch A Sketch: draw one continuous line with arrow keys/WASD or the mouse.
- `metronome.html` — Web Audio metronome with BPM slider, accented downbeat and a swinging arm.
- `simon_says.html` — Simon memory game with four coloured pads and tones; sequence grows each round.
