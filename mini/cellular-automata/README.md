# Cellular automata

Tiny text-mode automata, each self-contained.

- `life.py` — Conway's Game of Life on a torus, with a glider.
- `elementary.py` — Wolfram 1-D rules (`python elementary.py 30 20`).
- `langton.py` — Langton's ant on a wrapping grid.
- `brians_brain.py` — Brian's Brain (on / dying / off) on a random torus.
- `wireworld.py` — WireWorld electrons travelling along a wire.
- `highlife.py` — HighLife B36/S23 grown from the R-pentomino.
- `day_and_night.py` — Day & Night B3678/S34678 on a random torus.
- `cyclic.py` — cyclic CA: 5 states chasing each other into spirals.
- `sandpile.py` — abelian sandpile toppling from a single pile (`python sandpile.py 200`).
- `seeds.py` — Seeds B2/S: explosive pattern from two adjacent cells.
- `rule110_triangle.py` — Rule 110 grown from a single cell.
- `forest_fire.py` — forest-fire model with growth, lightning and spreading fire.
