# encoding

Byte/text encodings implemented by hand, each with a self-check.

- `base64_codec.py` — Base64 encode/decode verified against the stdlib.
- `hexdump.py` — `hexdump -C` style dumper (stdin-free; pass a file path or run the demo).
- `percent_encode.py` — URL percent-encoding and decoding.
- `rot_and_atbash.py` — ROT-N (default ROT13) and Atbash letter substitutions.
- `base32_codec.py` — Base32 encode/decode verified against the stdlib.
- `morse_code.py` — Morse code encoder/decoder.
