# automata

Finite and pushdown automata demos, standard library only. Run from this folder.

- `dfa.py` — DFA class plus "divisible by n" and "ends with ab" machines.
- `nfa_to_dfa.py` — subset construction turning an NFA into a DFA.
- `pda.py` — pushdown recognizers for balanced brackets and a^n b^n.
