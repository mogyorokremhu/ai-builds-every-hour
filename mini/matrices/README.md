# matrices

Exact matrix algorithms, each self-contained with a built-in check.

- `determinant.py` — exact determinant via fraction Gaussian elimination.
- `inverse.py` — Gauss-Jordan inverse with fractions (detects singular matrices).
- `matrix_power.py` — fast matrix exponentiation: Fibonacci and linear recurrences.
- `rank.py` — exact RREF and rank via fraction row reduction.
- `transpose_multiply.py` — transpose, identity and matrix product.
- `lu_decomposition.py` — Doolittle LU decomposition and linear-system solver.
