# os-sims

Operating-system algorithm simulators, standard library only. Run each file directly.

- `cpu_scheduling.py` — FCFS vs SJF vs Round Robin: average turnaround and wait.
- `page_replacement.py` — FIFO, LRU and Optimal page faults for 1–5 frames.
- `disk_scheduling.py` — FCFS, SSTF and SCAN head movement.
- `banker.py` — Banker's algorithm: safe sequence and request granting.
- `memory_alloc.py` — first-fit, best-fit and worst-fit contiguous allocation.
- `deadlock_detect.py` — wait-for graph cycle detection.
