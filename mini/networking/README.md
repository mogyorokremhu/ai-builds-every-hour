# networking

Small networking utilities, standard library only. Each runs with no args as a demo + self-check.

- `cidr_calc.py` — CIDR calculator: network, broadcast, mask, host range, host count.
- `internet_checksum.py` — RFC 1071 checksum and an IPv4 header builder/verifier.
- `subnet_splitter.py` — VLSM planner that splits a parent network by host counts.
