# math-art

Pictures from maths. Pure standard library, each file runnable on its own.

- `spirograph_svg.py` — hypotrochoid (spirograph) curves written to an SVG file.
- `mandelbrot_ascii.py` — the Mandelbrot set in the terminal with a character ramp.
- `lissajous_ascii.py` — Lissajous curves plotted on a character grid.
- `sierpinski_ascii.py` — Sierpinski triangle from Pascal's triangle mod 2.
- `rose_curve_svg.py` — rose curves r = cos(n/d·θ) written to an SVG file.
- `julia_ascii.py` — Julia sets in the terminal with a character ramp.
- `dragon_curve_ascii.py` — Heighway dragon curve from its paper-folding turn sequence.
- `barnsley_fern_ascii.py` — Barnsley fern via the chaos game, density plotted as characters.
- `hilbert_curve_ascii.py` — Hilbert space-filling curve drawn with box characters.
- `koch_snowflake_ascii.py` — Koch snowflake by recursive edge subdivision.
- `lorenz_attractor_ascii.py` — Lorenz attractor (RK4) density plot of the x-z projection.
- `golden_spiral_ascii.py` — golden spiral from quarter-circle arcs through Fibonacci squares.
- `newton_fractal_ascii.py` — Newton's-method basins of attraction for z³ − 1, one character per root.
- `pythagoras_tree_svg.py` — Pythagoras tree of recursive squares written to an SVG file.
- `cardioid_string_art_svg.py` — times-table string art (k=2 cardioid, k=3 nephroid) as SVG.
