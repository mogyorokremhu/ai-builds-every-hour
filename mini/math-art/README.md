# math-art

Pictures from maths. Pure standard library, each file runnable on its own.

- `spirograph_svg.py` — hypotrochoid (spirograph) curves written to an SVG file.
- `mandelbrot_ascii.py` — the Mandelbrot set in the terminal with a character ramp.
- `lissajous_ascii.py` — Lissajous curves plotted on a character grid.
