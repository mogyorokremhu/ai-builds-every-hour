# fractals

Fractals rendered as ASCII art, standard library only.

- `mandelbrot_ascii.py` — the Mandelbrot set via escape-time iteration.
- `sierpinski_chaos.py` — Sierpinski triangle from the chaos game.
- `julia_ascii.py` — Julia set for any complex constant (`python julia_ascii.py -0.4+0.6j`).
- `burning_ship.py` — the Burning Ship fractal (Mandelbrot with absolute values).
- `koch_snowflake.py` — recursive Koch snowflake outline plotted in ASCII.
- `newton_fractal.py` — Newton's method basins for z^3 - 1.
