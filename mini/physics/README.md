# physics

Tiny physics simulations (standard library only).

- `projectile.py` — projectile range/peak/flight time with an ASCII trajectory.
- `pendulum.py` — RK4 pendulum; shows how the period grows with amplitude.
- `orbit.py` — velocity-Verlet two-body orbit with energy-drift check.
- `spring.py` — damped spring-mass oscillator with an ASCII displacement plot.
- `collision.py` — 1-D collisions with a restitution coefficient; momentum/energy check.
- `doppler.py` — Doppler shift of a moving sound source or observer.
