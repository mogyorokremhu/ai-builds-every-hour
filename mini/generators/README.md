# generators

Small random generators. Each file is self-contained and runnable.

- `maze.py` — recursive-backtracker maze printed as ASCII (`python maze.py 12 6 42`)
- `names.py` — fantasy names from syllable tables (`python names.py 10 7`)
- `markov.py` — word-level Markov text generator (`python markov.py [file] 40 3`)
- `password.py` — memorable word-word-number passphrases (`python password.py 5 3 42`)
- `dungeon.py` — random rooms + corridors dungeon map in ASCII (`python dungeon.py 60 20 7`)
- `haiku.py` — template-based 5-7-5 haiku (`python haiku.py 3 1`)
- `lorem.py` — lorem-ipsum filler paragraphs (`python lorem.py 2 5`)
- `palette.py` — harmonious colour palettes with ANSI swatches (`python palette.py triad 3`)
- `bingo.py` — printable 5x5 bingo cards (`python bingo.py 2 9`)
- `tarot.py` — three-card past/present/future spread (`python tarot.py 5`)
- `riddle_math.py` — "think of a number" riddles with answers (`python riddle_math.py 3 1`)
- `planet.py` — invent random planets (`python planet.py 4 2`)
