# evolution

Evolutionary and local-search optimisation toys.

- `genetic_string.py` — evolve random text into a target phrase with crossover and mutation.
- `hill_climb_tsp.py` — 2-opt hill climbing with random restarts on a random city tour.
- `knapsack_ga.py` — genetic algorithm for 0/1 knapsack, compared against the DP optimum.
