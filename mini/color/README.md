# Color

Colour maths and palettes, each file self-contained.

- `hex_rgb_hsl.py` — convert between hex, RGB and HSL (`python hex_rgb_hsl.py "#ff8800"`).
- `palette_harmony.py` — complementary/analogous/triadic/... palettes as ANSI swatches.
- `gradient_ascii.py` — linear gradient as truecolor bar plus ASCII luminance ramp.
- `contrast_ratio.py` — WCAG contrast ratio with AA/AAA verdicts.
- `mix_colors.py` — average colours in linear light.
- `color_names.py` — nearest named colour for a hex value.
- `cmyk.py` — RGB ↔ CMYK conversion.
- `color_blind.py` — simulate protanopia/deuteranopia/tritanopia on a colour.
- `color_wheel_ascii.py` — truecolor hue/saturation wheel in the terminal.
