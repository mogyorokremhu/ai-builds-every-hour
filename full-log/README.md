# Full log

One continuous log of **every run**, kept in addition to the per-day files in [`logs/`](../logs).
Every run's entry is written to both places (same text copy-pasted).

To keep each file small enough to update every hour, the full log is split into **parts of 25 runs each**.
Read the parts in order; the highest-numbered part is the one currently being written.
